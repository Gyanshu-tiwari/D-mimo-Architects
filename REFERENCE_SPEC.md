# Calibre Reference Specification

## Global Design System

### Typography
- **Primary Font**: `Inter Variable`, `Inter`, `sans-serif`
- **h1**: `66px` | Line-height `68.64px` (1.04) | Letter-spacing `-4.29px` (-0.065em)
- **h2**: `54px` | Line-height `55.35px` (1.025) | Letter-spacing `-3.51px` (-0.065em)
- **h3**: `86px` | Line-height `86px` (1.0) | Letter-spacing `-7.31px` (-0.085em)
- **h4**: `30px` | Line-height `32.7px` (1.09) | Letter-spacing `-1.2px` (-0.04em)
- **h5**: `25px` | Line-height `30px` (1.2) | Letter-spacing `-1.05px` (-0.042em)
- **h6**: `23px` | Line-height `27.6px` (1.2) | Letter-spacing `-0.989px` (-0.043em)
- **p (Body)**: `18px` | Line-height `24.48px` (1.36) | Letter-spacing `-0.4px` (-0.022em)
- **Links/Nav**: `12px` to `14px` depending on context.

### Colors
- **Backgrounds**: 
  - Primary Base (Light): `rgb(255, 255, 255)` (`#ffffff`)
  - Off-White Base (Services, Blog): `rgb(245, 246, 247)` (`#f5f6f7`)
  - Dark Accent Base (Philosophy, Testimonials, Pricing): `rgb(16, 16, 20)` (`#101014`)
- **Text**:
  - Dark Primary: `rgb(10, 11, 18)` (`#0a0b12`)
  - Light Primary (on dark): `rgb(255, 255, 255)` (`#ffffff`)

### Layout & Spacing
- **Max Width**: Typically unconstrained `none` for sections, container widths vary between `1200px` to `1440px` for inner content.
- Sections utilize horizontal centering and large vertical paddings (approx `120px` to `160px` desktop).
