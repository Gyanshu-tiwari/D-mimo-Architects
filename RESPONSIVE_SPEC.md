# Responsive Specification

## 1440px (Desktop Large)
- Layout: Max width constrained to ~1280px or fluid with large horizontal paddings (px-16).
- Typography: Full sizes (`h1: 66px`, `h3: 86px`).
- Grid: 3 or 4 column grids for Services, Works, Testimonials.
- Interactions: Full hover effects active.

## 1280px (Desktop)
- Layout: Paddings reduce slightly (px-12).
- Grid: Maintains 3 columns for main lists.

## 1024px (Tablet Landscape)
- Layout: Padding reduces (px-8).
- Typography: Headings scale down roughly by 15-20% (`h1: ~56px`, `h3: ~72px`).
- Grid: 3 columns collapse to 2 columns for Services and Works.

## 768px (Tablet Portrait)
- Navigation: Desktop nav items hide. Hamburger menu appears.
- Layout: Padding reduces (px-6).
- Grid: 2 columns mostly collapse to 1 column or remain tight 2 columns depending on content.
- Typography: Headings scale down further (`h1: ~48px`, `h3: ~56px`).
- Images: Maintain aspect ratio but span full width of container.

## 390px (Mobile)
- Navigation: Full screen mobile menu overlay.
- Layout: Padding very tight (px-4).
- Grid: All grid layouts collapse to 1 column (stack vertically).
- Typography: Base headings (`h1: ~40px`, `h3: ~40px`).
- Ordering: Text usually stacks above images if side-by-side on desktop.
- Animations: Stagger times reduced or removed. Hover effects disabled.
